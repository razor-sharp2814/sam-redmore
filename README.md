# Sam Redmore

Static landing page for [samredmore.com](https://samredmore.com/).

## Structure

- `index.html` – the whole page (CSS is inline, no JavaScript)
- `assets/img/` – images (WebP, plus the JPG used for link previews)
- `favicon.ico`, `apple-touch-icon.png` – site icons

## Running locally

There's no build step. Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server
```

Then visit <http://localhost:8000>.
